# Atlas Query

1. Read `index.md`. Pick the pages that match the question or task.
2. Read those pages in `wiki/`, then follow links one level deep if needed.
3. Answer from the pages, citing them: `(wiki/<page>.md)`. If the atlas doesn't cover it, say so.
4. If the answer is reusable (a decision, a comparison, a how-to), offer to save it with `atlas-update`.
5. Never edit pages during a query unless the user asks.
